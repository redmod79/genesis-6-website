# Genesis 6: Sons of God - Study Website

**Live site: https://redmod79.github.io/genesis-6-website/**

A standalone MkDocs Material website presenting a comprehensive biblical analysis of the "Sons of God" in Genesis 6:1-4.

## Contents

- **10-part report** (`docs/report/`) - The main study, examining the question from every angle
- **28 supporting studies** (`docs/studies/`) - In-depth research on individual topics referenced by the report

## Building Locally

```bash
pip install mkdocs mkdocs-material
mkdocs serve
```

Then open `http://127.0.0.1:8000` in your browser.

## Structure

```
docs/
  index.md              # Homepage
  report/               # 10-part report series (00-09)
  studies/              # 28 supporting study folders
  javascripts/          # Verse popups, breadcrumbs, data files
  stylesheets/          # Custom CSS
mkdocs.yml              # Site configuration
```
